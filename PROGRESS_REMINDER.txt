## 4. MAP ENGINE ARCHITECTURE

### Key files:
- src/types/map.ts:           TypeScript types (MapPlace, MapNode, MapEdge, etc.)
- src/lib/mapEngine.ts:       loadMapData(), searchLocations(), aStar(), routeMetrics(), genInstructions(), getRoute()
- src/components/OCPMap.tsx:  Canvas-based map component - rendering, zoom/pan, search, routing
- src/components/MapPreview.tsx: Landing page map preview card
- src/components/DashboardMapCard.tsx: Reusable dashboard map card

### How rendering works:
- DPR-aware canvas rendering (devicePixelRatio)
- World-to-viewport transform: ctx.translate(offset) then ctx.scale(zoom)
- Places rendered as circles with labels at world coordinates
- Route rendered as animated dashed line with A/B pins
- Labels scale inversely with zoom (remain readable)

### How search works:
- Fuzzy scoring on place name, aliases, category, description
- Data-driven from places.json (only searches actual places)
- Returns sorted results with scores

### How routing works:
- A* pathfinding on node/edge graph
- Place -> place-node-connections.json -> graph node -> A* -> route path
- Route metrics calculated via pixelsPerMeter conversion
- Instructions generated from node labels + directional analysis
