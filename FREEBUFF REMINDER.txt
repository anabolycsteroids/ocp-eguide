## 1. PROJECT OVERVIEW

OCP eGuide is a campus navigation and information system for OCP Jorf Lasfar,
a large phosphate and fertilizer industrial complex near El Jadida, Morocco.

The system includes:
- Interactive satellite map with zoom/pan
- Search functionality for 90+ locations
- A* pathfinding/routing between locations
- Multi-language support (EN/FR/AR)
- Role-based dashboards (19 profiles)
- Guest/public API with QR codes
- Authentication system

## 4. MAP SYSTEM ARCHITECTURE

### Coordinate System
- **Canvas**: 1520 × 933 pixels (campus-map.png)
- **pixelsPerMeter**: 0.8786127167630058
- **Walking speed**: 1.4 m/s
- **Zoom range**: 0.3 to 3.0

### How Rendering Works
- DPR-aware canvas rendering (devicePixelRatio)
- World-to-viewport: ctx.translate(offset) then ctx.scale(zoom)
- Places rendered as circles with labels at world coordinates
- Route rendered as animated dashed line with A/B pins
- Labels scale inversely with zoom (remain readable)

### How Search Works
- Fuzzy scoring on: name, aliases, category, description
- Data-driven from places.json
- Returns top 10 results sorted by score

### How Routing Works
- A* pathfinding on node/edge graph
- Place → place-node-connections.json → graph node → A* → route path
- Route metrics via pixelsPerMeter conversion
- Instructions generated from node labels + directional analysis
